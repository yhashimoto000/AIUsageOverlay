この数字をどこまで信じてよいか

重複排除と分類は、どちらも「除外した」「決められなかった」という負の情報を持ちます。 それを隠すと数字が実態より確からしく見えるため、実績をここに出しています。 Cowork はローカルCoworkのみ。クラウドは含まれないため、Cowork全体の実績とは一致しない場合があります。

同じ記録を二重に数えていないか

Claude Code は 1 回の応答が複数行に書き出されるため、応答の識別子 （requestId と message.id）で同じものを 1 件にまとめています。 Codex はスレッドごとの識別子（session_meta.id）で数えます。 session_id は会話ツリーの根の ID なので、これで数えるとサブエージェントの分が消えます。

Cursor トークン累積（ダッシュボード API 傍受）

Cursor のローカル履歴にはトークン数が含まれていないため、 ダッシュボードページをロードするたびに API レスポンスを傍受して蓄積しています。 アプリが起動していなかった期間のデータは取得できません。

内訳

係数を変えたときの年換算

年換算 = 直近 3 か月の月平均 × 12。実績が 3 か月に満たない場合は取得できた月の平均。

削減係数 k は実測値ではありません。k = 1.0 は「AI が 1 時間かけた仕事を人がやっても 1 時間」 という置き方で、AI のほうが速いという前提を数字に入れていない状態になります （3 倍速なら削減は 2 時間ぶん = k 2.0）。一方で、AI が動く間の指示・レビューで 人が張り付いている時間は差し引かれていません。どちらも測っていないため、 社内で説明するときは k をいくつに置いたかを必ず併記してください。

従量課金だった場合の費用（参考値）

定額プランで実際に支払った額ではありません。同じトークン量を API の公開単価で 課金したと仮定した場合の金額です。効果額と直接引き算しても意味はありません （実際の支払いは契約プランの月額です）。
